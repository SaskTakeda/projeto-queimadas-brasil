🔥 Análise de Queimadas no Brasil

Uma análise exploratória dos focos de queimadas entre 2015 e 2024, investigando tendências, sazonalidade, diferenças regionais, biomas, estados e relação com o índice de seca.

Aluno: Théo Cubas Reis

GitHub Dashboard

O problema

Queimadas podem afetar biodiversidade, qualidade do ar, saúde pública, recursos naturais, produção agrícola e mudanças climáticas. O projeto utiliza uma base simulada para identificar padrões e períodos críticos.
